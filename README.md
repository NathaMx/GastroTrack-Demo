# GastroTrack
Sistema de Gestión Integral y Control Operativo para Restaurantes (Mux TechX Solutions).

## Estructura del Proyecto
- `backend/`: API REST en Node.js y WebSockets.
- `frontend/`: Interfaz en React + Tailwind.
- `database/`: Scripts SQL para PostgreSQL.
- `docs/`: Documentación técnica.

## Instrucciones de Instalación
1. Clonar el repositorio.
2. Renombrar `.env.example` a `.env` y configurar credenciales.
3. Ejecutar `npm install` en las carpetas backend y frontend.
